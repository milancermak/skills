# Skills

Collection of agent skills I use.

## Install

Paste this prompt into your coding agent:

```text
Install the available skills from ~/projects/skills for this agent. Use its standard user-level skills directory. Read all SKILL.md files and copy each complete skill directory. Preserve unrelated skills and leave identical files alone. If an existing destination differs, show the differences and ask before replacing it. Verify the installed files and report their paths.
```
